隐私政策

最后更新：2026 年 10 月 23 日　·　适用于 Chrome 扩展「SQL 结构化解析」及配套的网页版服务

一、我们是谁

本扩展及其配套服务（统称「本服务」）由 SQL 结构化解析 运营方（下称「我们」）提供。本政策说明我们在提供解析服务过程中收集哪些信息、如何使用、以及你有哪些权利。

联系我们：support@example.com（请在正式发布前替换为你的真实联系邮箱）。

二、我们收集的信息

信息来源用途
账号邮箱、加密后的密码 你注册时填写 创建账号、登录鉴权
登录令牌 登录后签发 维持登录状态。令牌只保存在你浏览器的扩展本地存储中，网页脚本无法读取
你提交的 SQL 语句 网页脚本或网页版调用 仅用于当次解析并返回结果
请求来源网站地址（origin） 浏览器上报 校验该网站是否在你的授权列表内
余额、充值订单记录 你的操作 计费、对账、开票
已授权网站列表 你的操作 控制哪些网站可以调用解析服务

三、我们不收集的信息

  • 不收集你的浏览历史
  • 不读取除「你授权的网站 + 你主动提交的 SQL」以外的任何网页内容
  • 不收集广告标识符，不做用户画像，不用于广告投放
  • 不出售、不出租、不交换你的个人信息
  • 不在你的设备上上传任何代码到第三方
关于 SQL 语句：解析请求会把 SQL 文本发送到我们的服务器。 我们只用它做当次语法解析，不会用于训练模型、不会与其他用户的 数据混用、不会用于广告。但请注意：请不要提交含有生产数据、密钥、 用户个人信息的 SQL——它会离开你的设备进入我们的服务器。

四、我们如何使用信息

  • 提供并维护解析服务
  • 处理充值、计费与退款
  • 检测并阻止滥用（比如异常高频的解析请求）
  • 履行法律法规要求的义务

我们不会将你的信息用于自动化决策或画像。

五、共享与披露

我们不会向第三方出售你的个人信息。仅在以下情形披露：

  • 获得你的明确授权
  • 法律法规要求，或为保护我们及用户的合法权益所必需

支付环节：充值订单会涉及支付渠道（当前为人工转账方式）， 我们只共享完成交易所必需的订单信息（如订单号、金额、状态）。

六、Cookie 与本地存储

网页版使用本地存储（localStorage）保存登录令牌和界面偏好， 不使用第三方 Cookie，不做跨站跟踪。

七、数据保留

  • 账号信息：账号存续期间保留
  • SQL 语句：不持久化保存，仅在内存中处理当次请求
  • 订单与余额记录：按法律法规要求保留（通常 5–10 年，用于财税审计）

八、数据安全

  • 全站 HTTPS 传输
  • 密码使用 bcrypt 加盐哈希存储，我们无法还原明文
  • 登录令牌为随机串，服务端可随时吊销
  • 生产环境数据库不直接暴露公网

九、你的权利

根据《个人信息保护法》《数据安全法》及 GDPR（如适用），你有权：

  • 访问你的账号信息、余额、订单记录
  • 更正不准确的账号信息
  • 删除账号及关联数据（法律要求保留的订单记录除外）
  • 撤销已授权的网站（扩展设置页可随时操作）
  • 撤回同意、注销账号
  • 导出你的数据

行使方式：发送邮件至 support@example.com，我们会在 15 个工作日内处理。

十、未成年人

本服务不面向未满 14 周岁的未成年人。我们不会主动收集未成年人的个人信息。 如发现未成年人的信息被误收，请联系我们删除。

十一、政策更新

本政策如有变更，我们会在本页面更新「最后更新」日期并通过扩展内的公告提示。 重大变更会提前 7 天通知。
