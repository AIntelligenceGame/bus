安装 Chrome 扩展 先看看怎么用

MySQL 语法 JSON 输出 按站点授权 解析在服务端

怎么用

1 · 授权网站

点扩展图标 →「授权当前网站」。只有你授权过的网站能调用解析服务，别人偷不走你的额度。

2 · 页面里调用

网页脚本调 window.sqlext.parse(sql)，拿到结构化结果。令牌留在扩展里，网页永远拿不到。

3 · 用结果

表名、字段、WHERE 条件、JOIN 关系、子查询、CTE 全部拆好，直接喂给索引分析或可视化工具。

// 在已授权网站的页面控制台里
const r = await window.sqlext.parse(
  'SELECT id, name FROM users WHERE status = 1'
);

r.statement.details.from;            // "users"
r.statement.details.selected_exprs;  // ["id", "name"]
r.statement.details.where;           // 条件结构
r.balance;                            // 剩余额度

能解析什么

语句解析出的信息
SELECT来源表、字段列表、WHERE 条件、JOIN 关系、GROUP BY / ORDER BY / LIMIT、子查询、CTE
INSERT / REPLACE目标表、插入列、值来源
UPDATE / DELETE目标表、影响列、WHERE 条件
CREATE TABLE / ALTER TABLE表结构、字段类型、主键、索引、约束
EXPLAIN / SHOW / SET语句结构与管理命令

基于 go-mysql-server / vitess 解析器，支持注释（含 /*! ... */ MySQL 特有注释）。
